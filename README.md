# 2D Boss Arena

## 프로젝트 소개
Unity와 C#으로 개발한 2D 보스 전투 프로젝트입니다.

플레이어는 보스의 다양한 공격을 피하면서 피해를 입히고, 보스는 여러 공격 패턴과 페이즈에 따라 전투를 진행합니다.

## 개발 환경
- Engine: Unity
- Unity Version: 6000.5.0f1
- Language: C#
- IDE: Visual Studio
- Platform: Windows
- Genre: 2D Action
- Version Control: Git / GitHub

## 주요 기능
- 플레이어 이동 및 조준
- 플레이어 공격 및 보스 체력 관리
- 보스의 3가지 공격 패턴
  - 돌진 공격
  - 충격파 공격
  - 부채꼴 공격
- 공격 전조 표시
- 체력에 따른 보스 페이즈 전환
- 공격 패턴별 대기 및 후딜레이 처리

## 주요 구현 내용
- **상태 기반 보스 AI:** `BossController`에서 Idle, Telegraph, Attack, Recovery, PhaseChange 상태를 관리하고 조건에 따라 전환
- **공격 패턴 관리:** `BossAttack`에서 돌진, 충격파, 부채꼴 공격을 분리하고 페이즈에 따라 패턴 선택
- **공격 전조 시스템:** 공격 방향과 범위에 맞춰 예고 표시를 활성화하여 플레이어가 공격을 예측할 수 있도록 구현
- **돌진 이동 및 벽 충돌:** `Rigidbody2D.Cast()`로 돌진 경로의 벽 충돌을 검사하고, 충돌 거리를 기준으로 이동 거리를 조정
- **돌진 중 충돌 처리:** `Physics2D.IgnoreCollision()`으로 돌진 중 보스와 플레이어 사이의 물리 충돌을 무시하고, 공격 판정은 별도로 처리
- **공격 판정:** `Physics2D.CircleCast()`로 돌진 경로상의 플레이어를 탐지하고, `Physics2D.OverlapCircle()`로 충격파 및 부채꼴 공격의 범위 내 대상을 탐지
- **보스 체력 관리:** 체력 감소와 사망 처리를 구현하고, 체력에 따라 보스의 페이즈가 전환되도록 구성

## 개발 과정에서 해결한 문제

**돌진 공격 중 벽과 플레이어의 충돌 처리**

초기에는 보스가 돌진할 때 벽에 부딪히거나 플레이어와 물리적으로 충돌하면서 의도한 공격 동작을 구현하기 어려웠습니다.

이를 해결하기 위해 `Rigidbody2D.Cast()`를 사용해 돌진 경로의 벽 충돌을 미리 검사하고, 충돌 거리를 기준으로 이동 거리를 조정했습니다.

또한 `Physics2D.IgnoreCollision()`을 활용해 돌진 중에는 보스와 플레이어 사이의 물리 충돌을 무시하도록 했습니다. 대신 `Physics2D.CircleCast()`를 사용해 돌진 경로상의 플레이어를 별도로 탐지하고 피해를 적용하도록 구현했습니다.

## 개발하면서 느낀 점
이번 프로젝트에서는 단순히 공격 패턴을 구현하는 것뿐만 아니라, 각 패턴이 어떤 순서로 실행되고 어떤 조건에서 다음 상태로 넘어가는지 고려하는 경험을 했습니다.

특히 돌진 공격을 구현하면서 물리 충돌과 공격 판정이 반드시 같은 방식으로 처리될 필요는 없다는 점을 배웠습니다. 문제를 해결하기 위해 충돌 처리와 공격 판정을 분리하고, Unity의 물리 API를 목적에 맞게 활용하는 방법을 익힐 수 있었습니다.
